About Trunked Radio

The trunked radio system is a professional private network communication solution based on wireless trunked communication technology, mainly targeting critical communication scenarios such as public safety, fire emergency, transportation and large campuses. The system adopts digital trunking technology and features professional communication capabilities including fast call setup, group calls, forced insertion/release and emergency calls, delivering stable and reliable voice and data communication services in complex electromagnetic environments.

Product Introduction

This trunked radio system adopts the internationally advanced PDT/DMR digital trunking standard and supports multiple services including voice, data and positioning. The system consists of a switching control center, base stations, dispatch consoles, mobile radios and handheld terminals, and can be flexibly networked according to user requirements to build a dedicated communication network covering city, campus or industry level.

Working Principle

The wireless trunked communication system centrally controls multiple communication channels through base stations and dynamically allocates channel resources on demand. The system uses Time Division Multiple Access (TDMA) technology, dividing one carrier into two time slots to support two calls simultaneously, doubling spectrum efficiency compared with traditional analog walkie-talkies.

Solution Features

  • Supports narrowband-broadband converged networking with smooth evolution, protecting user investment
  • Features fault degradation capability; single base station runs independently to ensure critical communication
  • Supports Direct Mode Operation (DMO) for direct terminal-to-terminal communication in areas without network coverage
  • Provides rich API interfaces for integration with video surveillance and GIS dispatching systems
  • Supports terminal GPS positioning, short data transmission and status information reporting
  • Features a complete network management system supporting remote device monitoring and fault diagnosis
